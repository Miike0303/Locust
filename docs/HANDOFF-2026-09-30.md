## Traps found this session

- **Codex runner hangs under load**: three concurrent sessions + my builds hung three runners. Symptoms: log stops growing, messages like "the command is still pending". Cap at 2 sessions, check log growth, and note that a session that hit this stops itself with exit 0 and an honest report.
- **Stop-rule text**: a brief that says `if you see the text "X", stop` makes a researcher that greps the repo find it in OTHER briefs and abort (happened once, harmless). Say "stop only on a real tool error" and forbid searching `tmp/`.
- **Briefs from a researcher may list several editable files**: restrict "Files to edit" to one file per lane with a regex script before dispatching; two lanes both listing `unity.rs` would collide.
- **Python on Windows**: backslash paths inside normal string literals break (`\U...`); use forward slashes or raw strings, and files not inline.
- **`ls -t */verification.md` and `Get-CimInstance` can take minutes** when the machine is busy; keep status checks light.
- **A writer's report may measure an older HEAD**: the typed-fields writer pinned `b0a17d2` and could not see cycle 110. Re-measure cross-lane claims on the combined HEAD.
- **The classifier blocks `Stop-Process`** on processes it cannot prove are the agent's own. Ask the user.
