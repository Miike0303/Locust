## How to run a session

1. `git switch -c <branch-from-task>` from the latest local tip of this queue.
2. Read the task brief below and the cited files; reproduce the defect or confirm the gap before changing code.
3. Implement test-first where a behavior changes; keep the change inside the stated files.
4. Run the stated checks; record exact counts and exit codes in the Log.
5. Commit with the stated Conventional Commit message; mark the task done with the SHA.
