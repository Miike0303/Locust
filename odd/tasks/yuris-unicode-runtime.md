## Exploration and design constraints
No documented native UTF-8 payload switch was established. Primary VNTranslationTools README describes SJIS tunneling plus runtime proxy; actual source, version, license, APIs and architectures still require inspection. Existing opaque-byte tokens are not allocation authority. Exact runtime bytes must survive conversion, measurement and rendering; a custom decoder alone is insufficient proof. Existing Replace lacks established atomic publication for script/map/DLL/config; recorded generation membership and strict pack/apply/rollback are mandatory before native deployment. YU-RIS font integration/runtime precedence are unproved.
One writer, bounded delegation, meaningful observed RED/GREEN for behavior, assessment-guided independent verification. RDD remains off. Delivery follows verified-main work-unit chain and exact-SHA two-platform CI before main delivery. No silent downloads/execution of binaries; inspect/pin any upstream source and license first. No global dependency installs or spending. No anti-cheat/process injection into unrelated processes. Synthetic owned process only initially; no game launch/control without a separately safe procedure.
